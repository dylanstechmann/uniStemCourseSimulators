## Candidate cases

1. A fictional inhibitor binds only the free enzyme and competes with substrate for the same site. Which simple inhibition model is most consistent with the stated binding competition? Which statement should accompany a simple inhibition diagnosis?
2. Use the catalytic parameters and total enzyme amount in the synthetic dataset. Calculate the initial rate at the listed substrate concentration with the Michaelis–Menten relation. Calculate kcat from Vmax and the listed total active-enzyme amount in the assay.
3. Use the stated kcat and Km inputs; preserve compatible units when calculating catalytic efficiency. Calculate kcat/Km and report compatible concentration and time units. Which interpretation of kcat/Km is appropriate under the stated model?
4. Compare the control and inhibitor parameters in the dataset under the stated simple models. Which apparent Km pattern is expected for the listed competitive-inhibitor input? Which pair of apparent parameter changes is associated with pure noncompetitive inhibition in the simple model?
5. A learner estimates parameters from a reciprocal plot built from a small set of rates. Why can a double-reciprocal plot distort parameter estimates? Which assay feature most directly supports interpretation of a measured rate as an initial velocity?
