# Calculus I course review handoff

This handoff targets Calculus I: Differential and Integral Calculus, package version 0.4.9. The [review snapshot](CALCULUS_1_REVIEW_SNAPSHOT.md) identifies the exact public files. The package remains partial, unreviewed and formative-only; no reviewer or approval is recorded.

## Review scope

- Review the proposed 14-week sequence, prerequisites, objective/outcome associations and mathematical level.
- Independently check the new MVT hypotheses, Rolle and uniqueness examples, finite-change bound, and representative prior items for limits, differentiation, optimization, integration and numerical error.
- Compare the week-4 inverse/exponential/logarithm reading with MIT OCW 18.01SC Unit 1 Part B; recalculate the inverse slopes, logarithmic, exponential and inverse-trigonometric derivatives, the logarithmic-differentiation results, the (1 + 1/n)ⁿ values and the pH sensitivity estimates, and confirm the branch and domain statements.
- Check the inactive portfolio's derivative signs, Newton iteration and root uniqueness, antiderivative, Simpson weights/error, units and blank-sensitivity result.
- Assess whether the two-component synthetic signal clearly distinguishes exact model arithmetic from data-based model selection and interpretation.
- Review sequencing, notation, accessible alternatives, manual accessibility and likely weekly workload. The proposed rubric is unweighted and does not grade prose.

## Author-side evidence and its limits

Historical 0.4.6 evidence: the focused Calculus I suite reported 82 passing tests, including recalculations for Simpson's rule, the exact integral, Newton steps and background sensitivity. The suite was not run for 0.4.7. Version 0.4.8 corrected the syllabus only. For 0.4.9 the Calculus I recalculation file recomputes all 75 numeric keys. The eight new keys use bisection-solved inverse values instead of 1/f′, centred numerical derivatives instead of the derivative formulas, and repeated multiplication for (1 + 1/n)ⁿ. A further test checks the values stated in the reading. The full-suite result is in the validation report. These author-side checks do not establish independent mathematical review, accessible learner usability, semester workload, student learning or university equivalency. Graded homework, midterm, final and a laboratory sequence remain absent; the portfolio is inactive and ungraded.
